## Overview

We model the equity options implied volatility (IV) surface using feedforward neural networks and compare against polynomial regression and parametric SVI baselines. The target variable is mid implied volatility; inputs are log-moneyness and time-to-expiry.

> **For full project context see [`docs/`](docs/):**
> - [`PROJECT_PLAN.md`](docs/PROJECT_PLAN.md) - design decisions, ticker selection, feature definitions, split rationale
> - [`DECISIONS.md`](docs/DECISIONS.md) - log of key choices made during development and why
> - [`TERMINOLOGY.md`](docs/TERMINOLOGY.md) - definitions of all project-specific terms (normalizedIV, atmIV, etc.)

## Data

Neither raw nor processed data is committed to this repo.

- **Source:** `tbloptionclosemarkhist_EQT_v2.00_<date>.zip` - daily close mark history for US equity options (2024)
- **Coverage:** ~252 trading days, ~1.5M option records per day
- **Processed dataset** (generated by `src/build_dataset.py`): 12 tickers (8 training + 4 held-out, see PROJECT_PLAN.md §3) filtered for quality, stored as `data/processed/iv_surface.parquet`. The pipeline runs in two passes - extraction writes an intermediate `data/processed/iv_surface_raw.parquet`, then feature engineering produces the final file (see DECISIONS.md "Two-pass extraction architecture").

## Setup

Requires Python 3.10+.

```bash
# macOS / Linux
python3 -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt

# Windows (PowerShell)
py -m venv .venv
.venv\Scripts\Activate.ps1
pip install -r requirements.txt
```

Register the venv as a Jupyter kernel so notebooks pick up the right environment:

```bash
python -m ipykernel install --user --name bu493-project
```

Then select the `bu493-project` kernel in any notebook.

> **Note on data:** raw zip files and processed parquet files are gitignored and not included in the repo. To reproduce the dataset from scratch, place the instructor-provided zip files in `data/raw/` and run:
> ```bash
> python src/build_dataset.py
> ```
> If the raw parquet already exists and you only want to re-run feature engineering:
> ```bash
> python src/build_dataset.py --skip_extract
> ```
> The final dataset will be written to `data/processed/iv_surface.parquet`.

## Pipeline

1. `src/build_dataset.py` - extract rows for the 12 chosen tickers from raw zips, filter, compute features, save to Parquet
2. `notebooks/descriptive_stats.ipynb` - sample coverage, descriptive statistics, surface shape visualisation
3. `notebooks/polynomial.ipynb` - polynomial Ridge regression baseline; degree and alpha tuning; test set evaluation
4. *(todo)* `notebooks/svi.ipynb` - SVI parametric baseline
5. *(todo)* `notebooks/neural_network.ipynb` - feedforward NN; hyperparameter tuning; comparison against baselines

## Evaluation

- **Statistical:** Out-of-sample R², RMSE
- **Economic:** Arbitrage violation frequency (calendar spread, butterfly spread constraints)
- **Data split:** Chronological - train Jan–Aug 2024, val Sep–Oct, test Nov–Dec
